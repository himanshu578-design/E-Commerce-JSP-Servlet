# 🛒 ShopNow - E-Commerce Web Application

A modern e-commerce web application with a user-friendly shopping experience and dedicated admin panel.

## 🚀 Features

- 🔐 User Authentication
- 🛍️ Product Browsing
- 🛒 Shopping Cart
- 📦 Order Management
- 💬 Messaging
- 👨‍💻 Admin Dashboard
- 📊 Product & Order Management
- 🎨 Modern & Responsive UI
